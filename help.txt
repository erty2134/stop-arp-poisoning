
- requires sudo
- note the routers mac before running

commands:
    - set to set a value
    - get to get a value
    - start to start a thread
    - stop to stop a thread
    - kill to kill a thread
    - or just type in the command name for other commands

what each command does
    help, displays this
    broadcast, sends rounds of icmp pings to wake devices and store there ips and macs in kernal arp cache
    threads, stops there arp poisoning
    ban, bans attacker off wifi
    exit or quit, quits.


basic steps
    1. help

    2. broadcast
    or
    add clientsip 192.168.1.1
    add clientsip 192.168.1.2
    add clientsip 192.168.1.3
    ...
    
    3. set poisoninterval 1
    4. get poisoninterval

    5. set cleaninterval 1
    6. get cleaninterval

    7. set isolateinterval 1
    8. get isolateinterval

    9. set targetip 192.168.167.67
    10. set targetmac 11:22:33:44:55:66

    11. start threads
    12. get threads

    13. set baninterval 1
    14. start ban
    15. get ban

    16. stop threads
    17. stop ban
    18. quit or exit
